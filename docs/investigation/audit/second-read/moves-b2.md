- Row count check: 52 ids, first `lastrespects` (CSV line 54), last `reflect` (line 105).
- Accuracy handling (GI:1229): `choice.accuracy/100 * boosted_accuracy(attacker accuracy stage)` is applied to every move, including `accuracy: true` self/status moves (Recover, Quiver Dance, Bulk Up, Agility, Pain Split, Trick Room...) which can never miss in Showdown. Defender evasion stage does not appear in the formula (only one `evasion_boost` mention in GI, not in the hit check). Not in my slice's rows as a verdict, but affects them whenever accuracy or evasion stages exist (confidence medium; not verified that no earlier code resets accuracy for self-target moves).
- Weather reads: CE:301 (Moonlight), CE:460 (Weather Ball) and CE:486 (Solar Beam else-if) read `state.weather.weather_type` directly instead of `weather_is_active` (ST:1509), so Air Lock/Cloud Nine suppression is ignored. Mega Sol is handled for Weather Ball and Moonlight/Morning Sun, not for Solar Beam charge/power or Electro Shot rain check.
- Rounding pattern: engine truncates heals, drain and recoil (`as i16`); Showdown rounds half up for Recover (battle-actions.ts:1265), drain (battle.ts:2188) and recoil (battle-actions.ts:1440, min 1). Affects Recover, Giga Drain, Double-Edge, Brave Bird, Steel Beam.
- Freeze-Dry BP x4 versus Water (CE:617) models the 2x override as a damage multiplier; equal for damage but applied to base power, so power-keyed effects would see 280. Not a rules difference otherwise.
- Light Clay does not exist in the engine item enum at all (no `LIGHTCLAY` match anywhere in src); belongs to the items slice if Light Clay is legal in Champions.
- Aurora Veil, Reflect, Light Screen set while the side already has them are ignored (GI:622), matching Showdown's failure.
