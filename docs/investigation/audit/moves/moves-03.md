# Audit: MOVES slice 03 (CSV lines 106-157)

Slice: `03-coverage-moves.csv` lines 106-157 (52 rows, Overheat .. Waterfall). Rows audited: 52. NOT AUDITED: none.

Build assumption: features `champions` + `bss` (champions implies no generation feature in Cargo.toml; the move table uses runtime `cfg!` branches, so I read the `else` (gen6+/gen9) branch where a move has several variants). `apply_champions_modifiers` (choices.rs:20704) only touches the moves listed there; of this slice it changes only Dragon Claw (slicing).

Verdict counts: LOGIC 13, MATCH 13, PLAIN 13, DATA 3, CORE 4, PARTIAL 2, MISSING 3, UNSURE 1.

Five most important findings:
1. King's Shield is MISSING in effect: the KINGSSHIELD volatile is set but is not in the protect check (generate_instructions.rs:1727-1742), not in `PROTECT_VOLATILES`/end-of-turn removal list (:153, :3555). It never blocks, never punishes contact, and never expires (blocks re-use). Champions un-bans it (pp 5).
2. Revival Blessing and Sheer Cold are MISSING: Revival Blessing is a table row with a `heal` flag and no code anywhere; Sheer Cold has BP 0 and no OHKO logic (no Ice immunity, no 20% accuracy for non-Ice users, no level rule).
3. Fire-type damaging moves and Scald do not thaw a frozen target (Showdown `frz.onDamagingHit`, `thawsTarget`). The engine only thaws the user (`CHOICE_THAWS_USER`). Affects Overheat, Fiery Dance, Blaze Kick, Bitter Blade, Scald.
4. Dire Claw: no secondary at all under `champions` (the non-champions arm at choice_effects.rs:68 is cfg'd out); Champions needs 30% random psn/par/slp. Also has a spurious high-crit flag and lacks the Champions `slicing` flag.
5. Several flag/data gaps that switch ability behaviour: Blizzard lacks `wind` and only gets perfect accuracy in Hail (not Snow); Leech Seed has a wrong `powder` flag (Overcoat/Grass-powder logic); Double Shock lacks `punch`; Taunt lasts 2 move attempts instead of 3; Rest does not fail at full HP.

## Notes

- Thaw-on-hit is absent engine-wide: Showdown `frz.onDamagingHit` (conditions.ts:117) cures a frozen target hit by any damaging Fire move (and `thawsTarget` moves). The engine has no such code (FREEZE appears only in the user-thaw check choice_effects.rs:979, the freeze roll generate_instructions.rs:1816, and berries). Other Fire moves outside this slice are affected the same way.
- Champions freeze override (champions/conditions.ts:31-55): thaw check 25% per turn plus a guaranteed thaw when the 3-turn counter runs out (startTime 3). The engine uses a flat 25% (THAW_CHANCE, generate_instructions.rs:78) with no 3-turn cap. Belongs to the status slice.
- Accuracy "true" moves (Kowtow Cleave, Haze, Spikes, Roar, Whirlwind, Wish, Shell Smash, rain Hurricane, etc.) are stored as 100.0 and multiplied by the user's accuracy stage (generate_instructions.rs:1229). Showdown skips accuracy entirely for them. The engine also has no evasion stat at all, so Double Team-style effects cannot be represented.
- Drain and recoil rounding (rows Bitter Blade, Wood Hammer): Showdown rounds half up with a minimum of 1 for recoil (battle-actions.ts:1440, battle.ts:2188); engine truncates (generate_instructions.rs:1550, :1566). Applies to every drain and recoil move.
- Heal Block is only "heal-flag moves cannot be used" (generate_instructions.rs:1645) with no duration. Showdown also blocks Wish, drain, Leech Seed, Leftovers, berries, Poison Heal via onTryHeal. Also Rest/Synthesis/Wish heals ignore it. Ability/item slices should check this.
- Ingrain is an enum token only (state.rs:199); no heal, no trap, no drag block.
- Dancer is an enum token only (abilities.rs:90); there is no `dance` flag in Flags (choices.rs:19436), no `bypasssub`, `defrost`, `thawsTarget` or `metronome` flags either. Bypass-substitute is approximated by the `sound` flag only (generate_instructions.rs:1438), so Taunt/Haze/Roar/Whirlwind bypass Substitute only because nothing blocks them, and non-sound bypassers would be blocked.
- Champions PP overrides (King's Shield 5, Wish 5) are not in the engine move table (Choice has no pp field); PP comes from the input state, and PP is only decremented below 10 (K6).
- Crit moves in this slice (Stone Edge, Drill Run, Psycho Cut, Blaze Kick) are correct as flags (1/8 branch, base 1/24 in champions, generate_instructions.rs:57) but are under K7.
- Dire Claw: the engine has a `#[cfg(not(feature = "champions"))]` implementation (choice_effects.rs:68) that is deliberately compiled out for Champions, leaving nothing in its place.
