# Audit: MOVES slice 01 (CSV lines 2-53, 52 rows)

NOT AUDITED: none (all 52 rows audited).

## Summary

- Slice: `03-coverage-moves.csv` lines 2-53 (earthquake ... mysticalfire), 52 rows, all `used=1`.
- Build assumption: features `champions` + `bss` only, so NO `genN` feature is on. Every `cfg!(feature="genN")` move branch in `choices.rs` therefore takes its `else` arm (gen9 numbers), `apply_champions_modifiers` (choices.rs:20704, called at :19344) is applied, and `src/genx/*` is the compiled engine (lib.rs:14).
- Reference: `data/moves.ts` plus `data/mods/champions/moves.ts` overrides. Champions overrides that touch this slice: encore, fakeout, ironhead (flinch 20), makeitrain (acc 95, SpA -2), moonblast (10% SpA -1), protect (pp 5). No other id in this slice has a champions override.
- Verdict counts: MATCH 10, PLAIN 21, DATA 12, LOGIC 7, MISSING 1, CORE 1, PARTIAL 0, UNSURE 0. (Sum 52.)
  - Of the 12 DATA rows, 11 are "G1 only" (accuracy `true` in Showdown, 100 in engine, see Notes G1). Only Make It Rain is a real table difference.
  - K1 (damage roll) applies to every damaging row; I did not tag those CORE. PLAIN/MATCH on a damaging row means "correct once K1 is fixed".

Five most important findings:
1. Make It Rain: engine BP 95 (champions override) vs Showdown 120 (champions mod does not change BP); accuracy 100 vs 95. SpA -2 self-drop is correct.
2. Sparkling Aria: burn cure is not implemented. The engine applies a `SPARKLINGARIA` volatile to the target that nothing ever reads or removes.
3. G1: every `accuracy: true` move (Swords Dance, Stealth Rock, Protect, Yawn, Substitute, Aura Sphere, Flower Trick, all self boosts/heals) is accuracy 100 in the engine and goes through `check_move_hit_or_miss`, which multiplies in the user's accuracy stage. With a negative accuracy stage these moves can miss in the engine, never in Showdown. Target evasion is not modelled at all.
4. Fake Out (champions: becomes unselectable after the first move): engine still offers it as a legal choice and just strips its effects; also when flinched on the arrival turn `last_used_move` is reset to None, so Fake Out is allowed again next turn (Showdown: not).
5. Recoil/drain rounding: Flare Blitz and Wave Crash recoil, and Leech Life drain, use truncation (and no minimum 1); Showdown uses `Math.round` (half up) with min 1 for recoil. Off by 1 HP on about half of hits. Also Encore: no `failencore` check (Encore/Mimic/Transform/Mirror Move/Struggle can be encored onto), Yawn: falling asleep at end of timer ignores Electric/Misty Terrain, Safeguard, abilities, sleep clause; Roost: pure-Flying user becomes typeless instead of Normal and is not made grounded.

## Notes

- G1 (engine-wide, not just this slice): `check_move_hit_or_miss` (generate_instructions.rs:1210-1230) computes `choice.accuracy/100 * boosted_accuracy(user accuracy stage)` with no exemption for `accuracy: true` moves or for self-targeted moves, and the table has no never-miss representation (default accuracy 100.0, choices.rs:20656). With any negative accuracy stage, Swords Dance, Protect, Substitute, Roost and the like can "miss" in the engine. Target evasion stage (`evasion_boost`) is never used in that formula, so evasion is ignored for every move.
- All damaging rows depend on K1; Outrage on K4; Flower Trick also K7 (crit branch). Not tagged CORE except Outrage.
- `use_last_used_move` and `use_damage_dealt` default to false (state.rs:1349-1350) and are only switched on by `set_conditional_mechanics` (genx/state.rs:1558) when the state contains Encore/Fake Out/First Impression/Bloodmoon/Gigaton Hammer (resp. Counter etc.). Any integration that builds `State` without calling it silently breaks Encore and Fake Out.
- Sparkling Aria leaves a permanent-until-switch `SPARKLINGARIA` volatile on the target. It has no reader, so harmless today, but it is state noise.
- Pivot moves are only checked at the call level (`flags.pivot`, generate_instructions.rs:3683). The detail of the following forced switch and Eject Button/Red Card interplay belongs to another slice.
- Knock Off: Showdown's removal also needs `source.hp`/target item still present and is blocked by Sticky Hold and by Mega stones of the matching species; engine implements Sticky Hold and all-species Mega stone protection (genx/state.rs:617-708).
- Protect chain: the engine increments `side_conditions.protect` at end of turn and resets it when no protect volatile is present (generate_instructions.rs:3555-3602). This matches Showdown's stall volatile (duration 2) in the cases traced.
- Champions Encore (champions moves.ts:309): target gets exactly 3 forced moves regardless of whether it already moved this turn. The engine's counter (forced move converted at execution time, removed on the 3rd use) gives 3 in both cases.
- PP: Choice has no PP field, so Champions PP changes (Protect pp 5) and Pressure/Spite effects are not representable here (K6).
