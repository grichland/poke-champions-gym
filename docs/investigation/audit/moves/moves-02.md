## Five most important findings

1. Curse (82): engine gives every user +1 Atk/+1 Def/-1 Spe and a no-op `CURSE` volatile. A Ghost user (the competitive use) should lose 50% max HP and put a 1/4-per-turn curse on the foe, and gets no boosts. Ghost branch absent, `CURSE` volatile is never read (st:173 only).
2. Glaive Rush (81): the drawback is never applied. `GLAIVERUSH` volatile is read in `dc.rs:308` (x2 damage taken) but nothing in the table or code sets it, clears it on the user's next move, or makes foes' moves always hit.
3. Psychic Fangs (72): no screen shatter (Reflect / Light Screen / Aurora Veil removed before damage). Only Raging Bull has that code (ce:803).
4. Pain Split (85): its effect lives in `choice_special_effect` (ce:1476), keyed on move id, and runs before the protect and accuracy handling (gi:2349 vs 1727 and 2363), so it works through Protect and on a rolled miss.
5. Freeze-Dry (95): Champions removes the 10% freeze secondary; engine keeps it (not in `apply_champions_modifiers`). Also Healing Wish (88) kills the user with no check that a replacement exists, Triple Axel (69) uses one accuracy check instead of three, Steel Beam (55) loses no HP on miss or Protect, Baton Pass (77) copies only boosts, Substitute and Leech Seed.

## Notes

Cross-cutting engine behaviour found while auditing (not owned by one row):

- Accuracy: `check_move_hit_or_miss` (gi:1229) multiplies `choice.accuracy` by the USER's accuracy stage for every move, including moves Showdown treats as `accuracy: true` or self-target status (Recover, Agility, Trick Room, Destiny Bond, screens, Toxic from a Poison type, ...). With a negative accuracy stage those moves can "miss" in the engine. Evasion stages are never used. Showdown skips the roll for those moves (battle-actions.ts:793-796).
- Special effects run too early: `choice_special_effect` (gi:2349) runs before Protect-handled choice fields matter and before the accuracy check, so any effect keyed on move id (Pain Split, Trick Room, Belly Drum ...) applies on a miss or through Protect.
- Rounding: heal, drain and recoil all truncate (`as i16`). Showdown: Recover-style heals `Math.round` (half up), drain `Math.round`, recoil `Math.round` min 1, `modify()` based heals (Moonlight, Morning Sun) round to nearest with half down. Affects every heal, drain and recoil move.
- Weather reads: several arms read `state.weather.weather_type` directly (Weather Ball ce:455, Moonlight/Morning Sun ce:294, Solar Beam ce:485) instead of an effective-weather helper, so Cloud Nine/Air Lock and Mega Sol are inconsistently handled. `get_weather()` (st:1492) and `weather_is_active` handle Cloud Nine but not Mega Sol.
- Light Clay: no `LIGHTCLAY` identifier found in engine src (outside gen1-3), so screen duration is a constant 5 (gi:150). Affects Reflect, Light Screen, Aurora Veil. Whether Light Clay is legal in the format was not checked.
- Dancer is an enum value without behaviour and `Flags` has no `dance` bit, so Quiver Dance (and any dance move) cannot trigger it.
- Showdown Champions disables Fake Out and First Impression after the first move action (`onDisableMove`); the engine keeps them selectable as no-ops (see firstimpression). Fake Out is in another slice and likely has the same gap.
- All damaging rows depend on K1 (damage roll) and, via crit branching, K7; this was not turned into CORE rows. Multi-hit K2 is relevant only to tripleaxel (see its own gap).
- Not verified in depth: engine handling of Magic Guard on Steel Beam self-damage, Showdown's `activePerHalf` screen multiplier is 0.5 in singles (matches).
