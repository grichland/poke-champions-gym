## Five most important findings

1. Horn Drill (OHKO) is MISSING: base power 0 and no special case, so `calculate_damage` returns `Some((0,0))` and the move can never do damage. Soak is also MISSING (no type change at all).
2. Final Gambit (and, by the same code path, all `fixed_damage` moves) ignores Protect/Spiky Shield/Baneful Bunker: `fixed_damage` is computed from `move_id` after `remove_effects_for_protect` has run, so the damage still lands and the user still faints.
3. Counter and Mirror Coat work through a Substitute (Showdown excludes Substitute hits from `DamagingHit`, so they fail), and they read a stale `damage_dealt` (reset only when the foe executes a non-switch move, so a foe switch leaves last turn's damage in place).
4. Brick Break does not shatter Reflect/Light Screen/Aurora Veil; Temper Flare never doubles; Alluring Voice never confuses; Parting Shot switches out even when both drops fail.
5. Swagger: accuracy 90 vs 85 (DATA), and its +2 Attack is blocked in the engine by Clear Body/White Smoke/Full Metal Body/Clear Amulet/Hyper Cutter/Substitute logic that is only meant for stat drops (`immune_to_stats_lowered_by_opponent` is not sign-aware).

## Notes

- N1 (accuracy true / evasion, affects many rows): the engine has no "never misses" notion. `check_move_hit_or_miss` (generate_instructions.rs:1229-1230) uses `choice.accuracy/100 * boosted_accuracy(user accuracy stage)`. Moves that are `accuracy: true` in Showdown (Spiky Shield, Baneful Bunker, Endure, Cosmic Power, Sticky Web, Chilly Reception, Snowscape, and the rain Thunder case) are stored as 100 and can "miss" if the user's accuracy stage is negative. Also the target's evasion stage is never applied (`evasion_boost` is written at :967 but never read for accuracy). Belongs to the core accuracy rewrite; check whether Champions allows accuracy/evasion boosts or drops at all.
- N2 (fixed-damage moves vs Protect): the Final Gambit finding generalises to Seismic Toss, Night Shade, Super Fang, Endeavor, Nature's Madness, Ruination (`fixed_damage` in choices.rs:20505). Worth a single regression test.
- N3: `is_grounded` (genx/state.rs:720) only considers Iron Ball, Flying type, Levitate/Eelevate and Air Balloon; Showdown also uses Gravity, Ingrain, Smack Down, Magnet Rise, Telekinesis. Affects Sticky Web, Spikes, terrain checks.
- N4: Heavy Slam weight ignores Autotomize and Float Stone; unknown whether Champions has them.
- N5: Weather duration is always 5 (choice_effects.rs:1610-1689); Icy Rock/Heat Rock/Damp Rock/Smooth Rock are not modelled. Big Root (drain/Strength Sap) is also not modelled. I did not check whether these items exist in the Champions item list; if they do, items slice owners should add them.
- N6: `calculate_damage_rolls` (generate_instructions.rs:4458-4487) uses `PokemonType::GHOST` for the immunity test of Final Gambit, Endeavor and Pain Split (these are Fighting/Normal/Normal moves), so that utility returns `None` against Normal-type defenders. Not used in turn resolution as far as I read, so low severity.
- N7: `damage_dealt` staleness (see Counter): it is reset only inside `generate_instructions_from_move` for a side that actually executes a non-switch move, so Metal Burst, Focus Punch, Avalanche and Counter/Mirror Coat can read last turn's value after the foe switches.
- N8: the engine applies `choice.boost` for every target through `apply_boost_instruction`, which calls `immune_to_stats_lowered_by_opponent` regardless of the sign of the boost; any move that RAISES the opponent's stat (Swagger, Flatter-like) is affected.
