# Audit moves-10 (slice MOVES, CSV lines 470-515)

Slice: 46 moves, Rock Wrecker .. Worry Seed. All 46 audited, none unfinished. Every row has used=0 (legal=1).
Engine compiled with `champions` + `bss` (no genN feature), so the `else` branch of every `cfg!(feature="gen1..5")` split and `genx` code is what counts.

Counts: MATCH 6, MISSING 16, LOGIC 14, DATA 7, CORE 2, PARTIAL 1, PLAIN 0, UNSURE 0.

K1 (damage roll) applies to every damaging move and is NOT repeated per row; a damaging row marked MATCH means "MATCH apart from K1".

Five most important findings:
1. Systemic "accuracy: true" encoded as `accuracy: 100.0` (Default). `check_move_hit_or_miss` (genx/generate_instructions.rs:1229-1230) multiplies by the attacker's accuracy stage, so never-miss moves (Shadow Punch, Smart Strike, Shift Gear, Spicy Extract, Tearful Look, Sunny Day, Soft-Boiled ...) and self-target status moves miss 25%+ once the user is at -1 accuracy. Evasion stage is stored (`evasion_boost`) but never read, and Sweet Scent has no evasion field (`StatBoosts` has none), so it does nothing.
2. Safeguard never expires: duration set to 5 (generate_instructions.rs:643-650) but the end-of-turn side-condition loop (2950-3001) only decrements Reflect, Light Screen, Aurora Veil, Tailwind. Safeguard also does not block confusion, and Wide Guard is the same (counter set, never read, never cleared).
3. Syrup Bomb: `apply_champions_modifiers` (choices.rs:20760) sets BP 90 but Showdown Champions keeps BP 60 and changes accuracy to 90 (mods/champions/moves.ts:1009); table accuracy is 85. The slow volatile (-1 Spe each turn, 4 turns) is in the enum only, no behaviour.
4. Ability/type/stat-changing and PP/berry moves are all absent: Role Play, Simple Beam, Worry Seed, Trick-or-Treat, Speed Swap, Spite, Stuff Cheeks, Teatime, Wonder Room, Spit Up, Swallow, Torment (volatile set, never restricts the move list), Venoshock (no 2x), Round (no 2x), Wide Guard (blocks nothing).
5. Snore/Sleep Talk are wrong in both directions: a sleeping Pokemon cannot act except via Sleep Talk (generate_instructions.rs:2336), so Snore is unusable asleep and usable awake; Sleep Talk can pick charge/nosleeptalk moves (state.rs:920-928).

## Notes

- ACC-TRUE systemic fix: represent `accuracy: true` as a never-miss value (or skip `boosted_accuracy` when `choice.accuracy` is the sentinel) and skip the hit roll for target=User moves. Rows affected in this slice: Shadow Punch, Shift Gear, Smart Strike, Soft-Boiled, Spicy Extract, Sunny Day, Tearful Look, Struggle, Safeguard, Role Play, Speed Swap, Stuff Cheeks, Swallow, Teatime, Wide Guard, Wonder Room, Sleep Talk. Only Shadow Punch, Shift Gear, Smart Strike, Tearful Look and Struggle are listed as DATA because it is their only fault; the rest carry the same flaw inside their own difference.
- Evasion: `evasion_boost` exists (state.rs:921, :994) and Showdown's accuracy uses it; `check_move_hit_or_miss` ignores it. Any evasion-changing move (Sweet Scent, Double Team, Minimize) is a no-op for hit chance.
- Substitute interaction for stat moves is hard-coded in `immune_to_stats_lowered_by_opponent` (state.rs:798) with no look at `bypasssub`/sound; it also applies to raises given to the foe (Spicy Extract).
- Heal moves use truncation (generate_instructions.rs:1184) where Showdown rounds (battle-actions.ts:1265); recoil the same (:1567 vs battle-actions.ts:1440). Applies to every heal/recoil move, not only the two rows above.
- Not my slice but seen: Own Tempo, Misty Terrain and Safeguard do not prevent confusion (state.rs:752); Safety Goggles absent from the powder check (generate_instructions.rs:1594); Mist is never decremented either (same loop as Safeguard); Sleep Talk's called move uses `p.choice.clone()` with a default move_index so PP/last-used handling for it needs a check; Champions sleep (2-3 turn start, 1/3 wake on action 2) and 1/8 paralysis and 25% thaw are modelled correctly (generate_instructions.rs:75-84, 172-179).
- Champions overrides touching this slice: only syrupbomb (accuracy 90), stuffcheeks (no onDisableMove) and trickortreat (made legal). No override for any other move here (conditions.ts only changes par/slp/frz).
