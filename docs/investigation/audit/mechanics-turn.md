1. 2. Rounding (M27, E20): recoil and healing moves truncate in the engine, Showdown rounds (Recover on odd HP, Brave Bird/Flare Blitz recoil); Toxic uses floor(maxhp*n/16) instead of floor(maxhp/16)*n and has no cap at stage 15.

4. Both sides entering at once (Q04, Q08, Q02, Q12): double faint replacement, both switching, lead turn all run side one first, never by speed or ability priority (weather wars, Intimidate, hazard KOs).
5. Locked moves not enforced at selection (L10): Outrage/Thrash/Petal Dance lock only blocks switching; the search may pick another move.
6. Win logic (W02, W03): both last Pokemon fainting always gives side two the win (Showdown: the side that fainted last wins, e.g. recoil user, Rocky Helmet victim, Destiny Bond attacker win; Explosion user loses); end-of-turn damage still runs after the last foe is KO'd, so side one can lose a won game.

## Notes (things that do not fit a row)

Engine behaviours noticed that belong to other slices: Rocky Helmet is `Heal(-0.166)` (floor(maxhp*0.166) != floor(maxhp/6) at multiples of 6) and is applied even when the hit went into a Substitute; Black Sludge damage is capped by missing HP; Solar Power likewise (E05); all healing/recoil uses truncation where SD rounds (M27); `Sitrus` thresholds (E51); `item_before_move` eats Sitrus at <= 25% only.
2. `moves_first` (GI:2623-2710) consults Custap Berry with `hp < maxhp/4` (SD: `hp <= maxhp/4`), irrelevant because Custap is Past in M-C but it adds an item-consume instruction to the turn; the wrapper should never build Custap sets.
3. Engine hail-vs-snow split: `Weather::HAIL` and `Weather::SNOW` are separate; every ability keyed to HAIL (Slush Rush speed Q19, Ice Body E07, Ice Face GI abilities.rs:1425 includes both) should be checked in the abilities slice for Snow handling.
4. Mid-turn reordering (gen 8+ queue re-sort) cannot change singles move order except after Mega Evolution (Q11/K8); the engine design (order fixed once) is therefore equivalent in singles. Priority/fractional priority are computed after switch-ins and Mega in both.
5. Pursuit path (GI:4169-4201, 4357-4428) always runs EOT with `SideOne` as first mover and without the replacing/force_switch guards used elsewhere; Pursuit is illegal in M-C so this is dead for us.
6. `s1_replacing_fainted_pkmn` only suppresses EOT when the replacing side's active had hp 0 AT THE START of the step; a pivot replacement step runs EOT through the normal path, which matches SD (residual after the replacement).
7. Unverified assumptions: Future Sight duration (3) read in engine (choice_effects.rs:1004), SD value taken from the futuremove slot condition (conditions.ts:379-426 uses move-set duration); weather/terrain `Air Lock` checks in weather-ability speed (Q19); hazard KO then ability firing (S08) needs one run.
8. Row counting: Section 3 row S14 and Section 4 rows E29-E31/E53 deliberately point at earlier rows (M07, M10, M01, Q25) and carry the same verdict, so they double count those findings; the ranked list below counts each underlying finding once.
