Five most important findings:
1. **Piercing Drill** (and by the same arm Unseen Fist): engine multiplies base power by 0.25 for every contact move, always (E abilities.rs:2256). Showdown applies 0.25x only when the target is actually protecting (bypassProtect set in `onHitProtect`, `sim/battle.ts:1314`, `mods/champions/scripts.ts:298`). Against a non-protecting target the engine does 4x too little damage.
2. **Leaf Guard**: `immune_to_status` does `LEAFGUARD => return weather_is_active(SUN)` (E generate_instructions.rs:791). With no sun it returns false immediately, skipping every other check (already statused, Misty Terrain, Safeguard, Substitute, type immunities), so a Leaf Guard mon can be re-statused. Harsh Sun is also not counted. Same early-return bug on Shields Down (line 788, other slice).
3. **Sturdy**: the "survive at 1 HP" code takes 1 off every hit on a full-HP Sturdy/Focus Sash mon, even non-lethal hits (E generate_instructions.rs:1491-1497). No OHKO-move immunity, no Mold Breaker bypass.
4. **Mega Sol** is only half done: damage and Weather Ball/heal moves use sun, but Solar Beam/Solar Blade still charge (and are halved in other weather), and Thunder/Hurricane/Blizzard accuracy ignore it. Showdown makes Mega Sol users' moves behave as in sun for all of these (`sim/pokemon.ts:2211`, `data/moves.ts` effectiveWeather calls).
5. **Contact-ability secondaries (Gooey, Poison Point, Spicy Spray)** are modelled as user-targeted secondaries on the attacker's move. Consequences: they fire when the hit lands on a Substitute (Showdown: no DamagingHit on a sub, `battle-actions.ts:1118`), they are wiped by the defender's Covert Cloak (generate_instructions.rs:3794), the stat-drop ones skip the attacker's Clear Body/Clear Amulet/White Smoke/Mirror Armor/Defiant/Competitive (source == target in `apply_boost_instruction`), Spicy Spray also fires on status moves (no contact/category check), and Poison Point is 33% not 30%.

Other notable: 15 abilities have no behaviour at all (Cute Charm, Illuminate, Electromorphosis, Illusion, Frisk, Imposter, Mirror Armor, Unnerve, Moody, Harvest, Synchronize, Quick Draw, Early Bird, Super Luck, Parental Bond). Early Bird is implemented in Showdown's `slp` condition, not the ability entry (the CSV said "no Showdown handler"). Magic Guard misses recoil and ability-sourced damage. Defiant/Competitive trigger once per lowered stat, Showdown once per boost event.

## Notes

- **Evasion is never applied to hit chance** (grep: `evasion_boost` appears only in boost bookkeeping and Fling-like power, generate_instructions.rs:967; `boosted_accuracy` uses accuracy only, :1202). Double Team/Minimize-style evasion, and therefore Keen Eye / Illuminate / Sniper-style "ignore evasion", have no effect in the engine. Belongs to the moves/core slice.
- **Mold Breaker handling is local**: `ignores_target_ability` is only consulted in `ability_modify_attack_against` and Disguise/Ice Face. It is not consulted in `immune_to_status`, `immune_to_stats_lowered_by_opponent`, Sturdy (generate_instructions.rs:1492), Shell Armor crit check, or Leaf Guard/Limber/Keen Eye/Water Bubble. Matters only if a Mold Breaker/Teravolt/Turboblaze mon is legal in Reg M-C.
- **Defender-ability effects modelled as attacker secondaries** (Gooey, Poison Point, Static, Flame Body, Effect Spore, Spicy Spray, Tangling Hair; also Rattled, Justified, Steam Engine, Weak Armor, Water Compaction, Thermal Exchange which target the defender): all share the Substitute-hit, Covert Cloak (generate_instructions.rs:3794, checks the DEFENDER's item) and Shield Dust (zeroes any Opponent-target secondary) interactions. Also defender-targeted secondaries land even if the defender fainted; Showdown triggers `onDamagingHit` abilities on a fainted holder too, so those match, but Rattled/Justified (Showdown: `onDamagingHit`, requires damage > 0) are applied by type even when the move is a status move or does no damage (not in this slice).
- `immune_to_status` Shields Down arm (line 788) has the same early-return bug as Leaf Guard (other slice).
- `is_grounded` (state.rs:720) ignores Gravity, Ingrain, Smack Down, Magnet Rise (volatile checked elsewhere), Telekinesis; affects Eelevate/Levitate Ground immunity (engine zeroes bp in abilities.rs:2630 regardless of Gravity).
- Population Bomb is fixed at 6 hits without Wide Lens/Skill Link (K2 family); Skill Link should make it 10.
- Poison/Burn status application from contact abilities goes through `immune_to_status`, so Fire/Poison/Steel typing immunities do work for those secondaries.
- Moxie/Chilling Neigh/Beast Boost/Eelevate use `defending hp == 0 && damage_dealt > 0`; a KO that leaves the move's `damage_dealt` 0 (e.g. hp already 0 via Destiny Bond order) is the only divergence, not significant.
- Champions sleep model (`chance_to_wake_up`, generate_instructions.rs:172: 0 -> 0.333 -> 1.0) matches `mods/champions/conditions.ts:11-30` (start 2 w.p. 1/3, 3 w.p. 2/3) for normal sleepers; only Early Bird is wrong.
