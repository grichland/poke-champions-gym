# 02 - Format support: Showdown `champions` mod vs poke-engine 0.0.48

Read-only investigation. Nothing was built or run. "V" = verified by reading code (file:line); "I" = inference.

## Summary (10 lines)
1. 52 rows: **26 none, 18 small patch, 1 large, 7 missing**. Several "none" rows are V only for the headline behaviour; see "Open questions".
2. Biggest gap (large): poke-engine is an expected-value branching engine, not a sampler. Damage uses 0.925 x max, multi-hit is a fixed count, and only kill/crit branches exist. A sampling engine needs a sampling layer (row 52).
3. Engine mega data is wrong for 2 of the user's 6 (V): Mega Garchomp Z gets Sand Force (Showdown: Levitate), Mega Golisopod gets Emergency Exit (Showdown: Tough Claws). Also Absol-Z, Lucario-Z, Drampa, Starmie differ (row 2).
4. Mega-turn speed order uses the pre-Mega speed (V by reading): the Mega state is reversed before `moves_first`. Showdown re-sorts with Mega speed in gen 9. This hits Mega Garchomp Z hardest (base Spe 102 to 151).
5. `apply_champions_modifiers` applies three number changes to the wrong field (V): Make It Rain gets BP 95 instead of accuracy 95 (BP stays 120), Crab Hammer BP 95 (should be accuracy 95), Syrup Bomb BP 90 (should be accuracy 90). Slash BP 80 and Freeze-Dry's lost freeze chance are not applied.
6. Missing outright: Disable and Torment/Imprison enforcement, Eject Button and Red Card (both legal in M-C), Emergency Exit/Wimp Out, Illusion, Imposter/Transform, Stance Change. Emergency Exit is the base-form ability of the user's Golisopod.
7. Confusion never expires, partial trapping never expires, Outrage-type locks are fixed at 3 turns, freeze has no guaranteed 3rd-turn thaw (small patches).
8. Format rules are fine: no Tera/Dynamax/Z, 60-option bring-3 preview, SP-to-stat formula identical at level 50, sleep/para/thaw/salt-cure/crit constants match, Item Clause is validation-only.
9. Showdown copy used: `C:\Users\user\Code\pcsa\.tools\vendor\pokemon-showdown` (HEAD c0845f33d, V via git). The path in the brief (`research\pcsa-rl\node_modules\pokemon-showdown`) does not exist.
10. Champions mod overrides: 257 move entries (190 "Past", 11 re-enabled, 25 BP, 15 PP, 5 accuracy, 8 flags, ~15 behaviour), 251 item entries (167 Past, 83 re-enabled incl. 81 mega stones, 1 Eject Button logic), 16 ability entries, 3 condition entries, 7 script hooks.
