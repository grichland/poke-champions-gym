## Where the original report is wrong or incomplete

1. Claim 3 / section 3 table ("Damage roll NOT branched"): wrong for the kill-possible case. `compare_health_with_damage_multiples` (`generate_instructions.rs:1038-1058`) rolls 16 values and the kill split uses `num_kill_rolls/16` (`:2445`). Summary line 9 ("always 0.925 x max") overstates this.
2. Rolls strictly greater than HP count as kills (`generate_instructions.rs:1051`). A roll exactly equal to HP is counted in neither bucket (`:1048`, `:1051`). Minor edge bug.
3. Claim 2 / section 4: "no library sampling" is wrong. `src/mcts.rs:112-127` and `src/mcts_threaded.rs:98` sample outcomes by weight. Only the generator is sampling-free.
4. Tera: it is disabled by `can_use_tera() -> false`, not compiled out (`src/genx/state.rs:1082-1085`).
5. Missed: two-hit moves are a fixed 2 (`generate_instructions.rs:2383-2385`).
6. Missed: the `MoveChoice::None` fallback for an empty move list is not at the cited line range; location still unverified.
7. Confusion self-hit damage (1/3, `generate_instructions.rs:1991-2023`) uses a float chain with floor steps and no roll; this is a second damage path not in the report.
